QMS 사고 비용 정산

손해배상금, 과태료, 매출 차감(Selling), 매입 차감(Buying), 고객사 보험 후 구상을 한 구조로 기록하는 설계안 (2026-11-09). 다른 사람에게는 공유용 주소 logistics.onharu.app/share/qms-claim을 보내세요. 정산 구조와 안 D·안 A만 담겨 있습니다.

  • 사고 비용 정산 구조돈의 흐름도, 정산 라인, 처리 방식별 예시, 지표
  • 입력 화면 안 D · 청구별 3줄 입력 직원용 추천요구받은 돈 → 회사가 한 일 → 돌려받은 돈
  • 입력 화면 안 A · 비용·정산 탭담당 부서용, 정산 라인을 직접 편집
  • 입력 화면 안 B · 처리 방식 선택형방식을 고르면 라인이 자동으로 만들어짐
  • 입력 화면 안 C · 진행 타임라인형몇 달 걸리는 구상 건 추적용
