자료 구조

CTU Code 자료는 역할이 다른 세 문서로 나뉩니다. 먼저 1497에서 원칙을 확인하고, 계산표나 기술 배경이 필요할 때 1498을 찾아보는 순서가 가장 간단합니다.

문서역할구성먼저 볼 때
MSC.1/Circ.1497지켜야 할 적입 실무규칙본문 13장 + 부속서 10개책임, 계획, 적입·고정, 인수 절차를 확인할 때
MSC.1/Circ.14981497을 적용하기 위한 정보자료IM1~IM10래싱 표, CTU 제원, 하중 분포와 사례가 필요할 때
MSC.1/Circ.1531CTU 서비스 제공자 실사 체크리스트업체 점검 질문적입·포장 업체를 선정하거나 평가할 때

어떻게 읽을까

  1. 처음 읽는 경우: 3장 핵심 요구사항 → 5장 운송 조건 → 9장 화물 적입 → 부속서 7 적입·고정 순으로 봅니다.
  2. 현장 업무 중인 경우: 자료실 첫 화면의 ‘작업 순서로 보기’에서 현재 단계에 맞는 해설을 고릅니다.
  3. 수치와 계산이 필요한 경우: 1498의 IM5 빠른 래싱 가이드와 IM6 하중 분포, 1497 부속서 7의 계산 항목을 함께 확인합니다.

CTU Code의 범위

화물컨테이너, 스왑바디, 도로차량과 철도화차 등 화물운송단위의 안전한 적입과 고정을 다룹니다. 적입자뿐 아니라 화주, CTU 운영자, 도로·철도 운송업자, 터미널, 운송인과 수하인까지 각자의 책임과 정보 전달을 설명합니다. 기존 법령과 위험물 규정을 대신하지 않으며, 실제 작업에서는 국가 규정과 운송 계약을 함께 확인해야 합니다.
