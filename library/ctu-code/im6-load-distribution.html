IM6 복합운송 하중 분포와 축하중

원문 대조 확인 2026-10-01

정보자료 6(MSC.1/Circ.1498 IM6)은 화물 무게에 따라 화물 무게중심이 어디까지 옮겨 가도 되는지를 한 장의 그림으로 보여 주는 하중 분포도(LDD)를 40피트 컨테이너를 예로 설명합니다. 컨테이너 한도만 지켜도 철도 화차나 도로 트랙터의 축이 먼저 넘칠 수 있으므로, 복합운송에서는 컨테이너·화차·샤시의 분포도를 겹쳐 가장 좁은 범위를 찾아야 한다는 것이 요지입니다. 세 편의 학술 논문을 저자 허락을 받아 옮긴 참고 자료이며 CTU Code의 요구사항은 아닙니다.

기본 개념 (§1, §2.1)

  • 무게중심 편심: ISO 830의 정의를 따라, 컨테이너 무게중심이 네 하부 코너 피팅 중심을 잇는 대각선의 교점에서 종방향·횡방향으로 벗어난 거리입니다(§1.2).
  • 적재중량: 최대 허용 총질량에서 자중을 뺀 값이며, 컨테이너에 딸리지 않은 고정재와 더니지도 이 안에 들어갑니다(§1.3).
  • 컨테이너 분포도 LDD(C): 총질량 30,480kg, 자중 4,000kg, 적재중량 26,480kg인 컨테이너를 예로, 컨테이너 무게중심 편심이 5%와 10%가 되는 화물 무게중심의 경계를 그립니다(§2.1.1). 화물이 무거울수록 경계는 컨테이너 중심 쪽으로 좁아집니다(§2.1.2).

화차와 트레일러의 분포도 (§2.2~§2.4)

차량분포도를 정하는 한도원문 예
2축 컨테이너 화차선로 등급별 최대 축질량(A 16t · B 18t · C 20t · D 22.5t), UIC 적재 지침의 축하중 불균형 2:1, 선로 등급·속도별 적재중량29.2t 화물의 무게중심이 바닥 끝에서 6.7m(중심은 6.39m)이면 축질량 18.9t·21.1t로 C 등급 20t 초과(§2.2.4)
3축 45피트 신축식 세미트레일러킹핀 최대 하중, 3축 최대 하중, 연결차량 총질량(GCM)·세미트레일러 총질량, 킹핀·3축 최소 하중(각각 최대 세미트레일러 질량의 25%)킹핀 기술 허용 하중은 15t이지만, 2축 트랙터(최대 18t, 자중 8.2t 가정)를 쓰면 9.8t로 제한(§2.4)

화차 분포도에서는 축 곡선들이 한 점에서 만나므로, 가장 무거운 화물을 실으려면 무게중심이 화차 정중앙에 있어야 합니다(§2.2.4).

겹쳐 보기: 복합운송 분포도 (§3)

  • 화차나 샤시 입장에서는 컨테이너 자중도 화물이므로 이를 포함한 LDD(W+C), LDD(T+C)를 그려 LDD(C)와 겹칩니다. 도표 왼쪽 축은 화물 질량, 오른쪽 축은 컨테이너 총질량이라 두 가지를 한꺼번에 점검할 수 있습니다(§3.1.1, §3.2.1). §3.1.1에는 "LLD"로 적혀 있습니다(원문 표기, LDD의 오기로 보임).
  • 철도: 예시 화차는 선로 등급 C에서도 컨테이너 적재중량을 다 쓸 수 없습니다(§3.1.2).
  • 도로: 최대 적재중량까지 올바른 분포는 3축 트랙터일 때만 가능합니다. 2축 트랙터로 킹핀 하중이 제한되면 무게중심을 문 쪽으로 옮겨 컨테이너 한계 가까이 두어야 합니다. 문이 뒤를 향하게 실었을 때 화물 무게중심이 앞쪽 절반(앞벽 쪽)에 있으면 트랙터가 과적됩니다(§3.2.2).
  • 도로·철도를 모두 겹친 예: 화물 15t까지는 어느 분포도도 넘지 않습니다. GCM 40t 조건에서 최대 화물은 22t입니다. 또 선로 등급 C 화차의 축하중 때문에 화물 무게중심 편심은 최대 3.6%까지 허용됩니다. GCM 44t이 허용되면 적재중량 26t을 다 쓸 수 있지만 선로 등급 C를 넘어 화차로는 보낼 수 없습니다(§3.3.2, §3.3.4).
  • 사용 예: 480kg 팔레트 44개(화물 21.12t, 컨테이너 총질량 25.12t)를 아래 단 30개, 위 단 앞쪽 6개·문 쪽 8개로 실으면 화물 무게중심 편심 1.024%, 컨테이너 무게중심 편심 문 쪽 1.020%로 모든 분포도 안에 듭니다(§3.3.3).

현장 체크포인트

  • 22t, 3.6% 같은 숫자는 원문 예시 차량의 값입니다. 실제 화차·샤시·트랙터 제원으로 다시 확인합니다.
  • 무거운 적재일수록 허용 편심이 줄어듭니다. 무거운 화물은 종방향으로 컨테이너 중앙 가까이 둡니다.
  • 도로 구간에서 안쪽 벽(앞벽) 쪽에 무게가 몰리면 킹핀 하중이 커져 트랙터 뒤축이 먼저 넘칩니다. 2축 트랙터를 배차받으면 더 민감합니다.
  • 철도 구간이 있으면 선로 등급과 화차 형식에 따라 실을 수 있는 화물 질량 자체가 줄어듭니다. 철도 운영자에게 선로 등급을 확인합니다.
  • 편심은 화물만이 아니라 컨테이너 자중을 포함한 총질량 기준으로 봅니다.
