CTU Code를 CubeStow에 적용한 기준

원문 대조 확인 2026-10-01

CubeStow가 CTU Code의 어느 부분을 계산과 결과에 사용했는지 한곳에 모았습니다. 이 표는 제품 구현 범위를 설명하는 참고 자료이며, 프로그램 결과가 현장 점검이나 공식 원문의 판단을 대신하지 않습니다.

적용한 기준

기능적용 내용근거 해설
컨테이너 선택20ft·40ft·40HC·45HC 드라이 컨테이너의 대표 내부 치수와 적재 한도를 사용합니다. 실제 장비의 명판과 내부 치수는 현장에서 다시 확인해야 합니다.CTU 특성
중량·공간 검사화물 합계가 적재 한도를 넘는 배치를 만들지 않고 공간 사용률, 무게중심과 바닥 선하중을 계산합니다.하중 분포
운송 중 힘도로·복합철도·해역 조건의 종·횡·수직 가속도 계수를 고정 계산에 사용합니다.운송 조건
마찰·블로킹마찰계수, 형상 고정, 빈 공간 합계 15cm 원칙과 더니지 조건을 배치 검사에 반영합니다.적입 계획
고정재 계산방향별 미끄럼·전도 조건을 비교하고 각재와 못, 에어백 간극, 래싱 필요량을 계산합니다.고정 평가 · 고정 계산
래싱 수량IM5 빠른 래싱 가이드의 표와 마찰 보간, MSL 환산을 이용해 필요한 줄 수를 구합니다.빠른 래싱 가이드
고정점 한도바닥 고정점과 위쪽 래싱 고리의 허용하중을 구분하고, 래싱재와 고정점 가운데 약한 쪽을 한도로 사용합니다.고정점 허용하중
한국 도로 한도차량 총중량과 축하중을 추정하고, 한국 도로 운송용 적재 한도를 별도 선택값으로 제공합니다.한국 도로 한도 · IM6 하중 분포
작업 결과적재 순서, 고정재 권고와 계산 결과를 PDF·Excel 작업 자료로 내보내 현장 확인과 기록에 활용합니다.적입 완료 후

적용하지 않은 범위

위험물 분류와 서류, VGM 신고, 실제 CTU의 CSC 명판·검사기한·손상, 결로와 훈증가스, 냉동·탱크·벌크 CTU, 봉인 번호, 작업자 교육·자격, 수작업 부담과 현장 장비 상태는 계산하지 않습니다. 개별 컨테이너와 차량의 실제 제원, 고정재 상태와 현장 조건은 담당자가 별도로 확인해야 합니다.

이 해설은 AI가 원문을 바탕으로 작성했습니다. IMO·ILO·UNECE가 만들거나 검토한 공식 번역이 아니며, 판단은 연결된 공식 원문을 기준으로 하세요.
