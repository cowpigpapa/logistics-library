IM7 수작업 취급 — 손으로 싣고 옮길 때

원문 대조 확인 2026-10-01

정보자료 7(MSC.1/Circ.1498 IM7)은 상자를 손으로 쌓거나 대차를 밀어 CTU에 싣는 작업에서 적입자가 다치지 않는 법을 다룹니다. 들기, 내리기, 나르기, 밀기, 당기기가 모두 수작업 취급이며, 원문은 이것이 작업장 부상의 3분의 1이 넘는 원인이라고 합니다(§1.2). 무게만이 아니라 횟수, 나르는 거리, 들고 놓는 높이, 비틀거나 숙이는 자세가 함께 위험을 만듭니다(§1.1). CTU 안은 좁고 어둡고 더워서 같은 작업도 창고보다 힘듭니다.

누가 무엇을 하나 (§1.4~§1.7)

  • 고용주: 위험한 수작업을 되도록 없애고, 없앨 수 없는 작업은 위험을 평가해 줄입니다. 작업 방식은 적입자와 의논해 정합니다. 위험을 아는 사람이 현장 작업자이기 때문입니다.
  • 적입자: 정해진 작업 방식과 제공된 장비를 쓰고, 위험한 취급 작업을 발견하면 알립니다.
  • 수작업을 없앨 수 없으면 기계식 취급 장치(MHD)로 위험을 줄이는 것이 기본입니다(§1.4).

무게 한도는 어떻게 보나

IM7에는 "몇 kg까지 들 수 있다"는 숫자 한도가 없습니다. 원문은 들 수 있는 무게와 안전하게 들 수 있는 무게는 다르니 쉽게 다룰 수 있는 것보다 많이 들지 말라고만 합니다(§2.11). CTU Code 본문도 사람이 드는 포장화물의 무게 제한을 지키라고만 하고 숫자는 각 나라 규정에 맡깁니다(1497 부속서 7 §3.3.1). 국내에서는 하루 10회 이상 25kg 이상을 드는 작업, 하루 25회 이상 10kg 이상을 무릎 아래·어깨 위·팔을 뻗은 자세로 드는 작업이 근골격계부담작업에 해당하므로(고용노동부 고시) 이 값을 현장 기준으로 삼을 수 있습니다.

들 때의 기본 자세 (§2)

  1. 들기 전에 계획합니다. 보조 장비를 쓸 수 있는지, 어디에 놓을지, 도움이 필요한지 보고, 버려진 포장재 같은 걸림돌을 치웁니다. 멀리 옮길 때는 중간에 탁자에 내려 손을 고쳐 잡습니다.
  2. 짐을 허리 가까이, 몸에 붙여 듭니다. 무거운 쪽을 몸 쪽으로 둡니다. 멀면 먼저 몸 쪽으로 끌어당깁니다.
  3. 발을 벌려 안정되게 서고, 짐을 감싸 안듯 잡습니다.
  4. 허리·엉덩이·무릎을 조금씩 굽힌 자세로 시작합니다. 허리만 완전히 숙이거나 쪼그려 앉지 않습니다.
  5. 들어 올리는 중에 허리를 더 숙이거나 비틀지 않습니다. 방향은 발을 옮겨 바꿉니다.
  6. 짐을 잡은 뒤에는 고개를 들어 앞을 보고, 홱 잡아채지 않고 부드럽게 움직입니다.
  7. 정확한 위치가 필요하면 먼저 내려놓은 뒤 밀어서 맞춥니다.

보조 장비와 밀고 당기기 (§3~§5)

핸드 트럭무겁고 잡기 어려운 짐작은 바퀴는 바닥에 힘이 몰려 바닥이 꺼질 수 있음

팔레트 트럭팔레트를 제자리로 밀어 넣기리퍼의 알루미늄 T자형 바닥에 맞는 바퀴인지 확인
호이스트·지게차위 단 팔레트 놓기CTU 안 높이가 충분한지 위험성 평가
  • 손잡이는 허리와 어깨 사이 높이가 좋고, 브레이크가 없거나 약한 장비는 멈추기 어렵습니다(§4.3, §4.4). 장비는 정기 점검하고 고장을 신고하게 합니다(§5.1).
  • 밀고 당기는 위험은 TILE(작업·개인·짐·환경)로 봅니다(§5.7). 평평한 바닥에서 잘 정비된 대차로도 짐 질량의 2% 이상 힘이 들고(400kg이면 80N), 울퉁불퉁한 바닥에서는 출발할 때 10%까지 늘어납니다. 400kg을 1:12(약 5°) 경사로로 올리면 30kg 넘는 힘이 필요하므로 경사로에서는 동료의 도움을 받습니다.
  • 짐 너머가 보이고 조향·정지를 할 수 있으면 당기기보다 밀기를 택하고, 걷는 속도를 넘지 않습니다.
  • 햇볕에 달궈진 금속 CTU 안은 금세 열탈진을 부를 수 있고, 어두운 안과 밝은 밖을 오가는 일도 부담입니다(§5.7.4).

현장 요점

  • 송하인은 다칠 위험이 있으면 포장화물에 무게와, 무게중심이 치우친 경우 무거운 쪽을 잘 보이게 표시합니다. 1~2kg 단위면 충분합니다(§6).
  • 위험한 수작업은 보조 장비, 짐 나누기, 여러 개 한꺼번에 들지 않기로 줄입니다(§6.1.3).
  • 사람마다 키와 힘, 지금 가진 통증이 다릅니다. 특별한 체력이 필요한 작업은 누가 어떻게 할지 따로 정하고, 장비 사용법은 교육합니다(§5.7.2). 적입 인력 교육에는 안전한 수작업 취급이 들어가야 합니다(1497 §13.1.3).
