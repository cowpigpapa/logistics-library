## 확인했지만 문서에 쓰지 않은 것 / 쓰지 않은 이유
- 보정이자 일수 계산 방식(초일 산입 등): 원문 확인 못 함 → 예시에 "단순 계산" 표시.
- 세액 끝수 처리(10원 미만 등): 원문 확인 안 함 → 예시 숫자가 끝수 문제 없는 값이 되도록 가정.
- 부가가치세 부족분에 대한 가산세 기준: 확인 안 함 → "별도 기준으로 계산"이라고만 씀.
- UNI-PASS 메뉴 이름: 확인 안 함 → 쓰지 않음.
