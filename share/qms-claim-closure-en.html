For: developers · Baseline: current Irregularity Closure screen · Written 2026-11-24 · Blue numbers match the markers on the redesigned screen · LXP = LX Pantos (our company)

2. Layout

  • Whole screen: 3 stacked sections — Progress & Result → Claim Result → CAPA. Keep the black divider lines between sections.
  • Progress & Result, CAPA: current Split screen 50:50 (input left, history right), unchanged.
  • Claim Result header: red Claim Result tab + summary bar on its right (black 'Summary (USD)' label + 4 cells), shown as a separate card with a small gap above the cost panel.
  • Claim Result body: Split screen 50:50 — payments left, recoveries right. Both tables use the same columns and widths.
  • Above each table: title and guidance on the left, + / − buttons on the right.
  • Below about 1,150px screen width, payments and recoveries stack vertically and the tables scroll horizontally.
  • Suggested column widths (px): Select 30 · Party 124 · Type (rest) · Currency 88 · Amount 78 · In USD 76 · Remark 104 (at 1,600px screen width).

5. Summary calculation (USD)

ItemCalculation
LXP paidSum of In USD for payment rows where Paid by = LXP (P1–P4)
Insurer / 3rd party paidSum of In USD for payment rows where Paid by = LXP insurer, Vendor or Customer (P5)
LXP recoveredSum of In USD for all recovery rows (R1–R5)
LXP net lossLXP paid − LXP recovered · if negative (more recovered), relabel as 'LXP net gain' and show the absolute value
  • Format: USD, thousands separator, 2 decimals.
  • Recalculate immediately when a row is added, changed or deleted.
  • Insurer / 3rd party paid is not part of the LXP net loss (same as the planning draft formula).

  • The first three cells colour the text only; only the result cell gets a background, so the eye goes to the result first.
  • If the net amount is 0, show it grey and keep the 'LXP net loss' label.
  • The result label (net loss / net gain) changes too, so the state is not shown by colour alone.

6+ / − buttons

  • Position: top right of each table (payments and recoveries separately).
  • + : adds one empty row at the bottom. Suggested default Currency for a new row: USD.
  • − : deletes the checked rows. Disabled when no row is checked.
  • Header checkbox selects / clears all rows in that table.
